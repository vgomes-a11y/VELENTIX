# Valentix · Portafolio de Valentina Gomes Rojas

Sitio estático (HTML, CSS y JavaScript): no necesita instalación ni dependencias.

## Qué incluye

Todos los archivos están en una sola carpeta (sin subcarpetas) para que sea fácil subirlos a GitHub.

- `index.html`: la página completa (los estilos están dentro del mismo archivo).
- `logo.png`, `foto-valentina.jpg`, `proyecto-1-portada.jpg`, `proyecto-2-boletin.jpg`, `proyecto-2-paginas.jpg` y `uniplata-*.png`: las imágenes.
- `404.html`, `robots.txt`, `.nojekyll`, `.gitignore` y `LICENSE`.

## Publicar en GitHub Pages

1. En github.com crea un repositorio nuevo y déjalo público.
2. Sube **el contenido de esta carpeta** (no el `.zip`): *Add file > Upload files*, arrastra todos los archivos y haz *Commit changes*.
3. Ve a *Settings > Pages*, en *Source* elige *Deploy from a branch*, rama `main`, carpeta `/ (root)`, y guarda.
4. En uno o dos minutos el sitio aparece en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

Los nombres de los archivos distinguen mayúsculas y minúsculas: no los cambies.
